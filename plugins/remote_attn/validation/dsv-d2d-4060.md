# DSV Remote D2D：4060 与 CPU/TP2 验证

日期：2026-11-04～05。范围：[后端协议与限制](../DSV-D2D-REMOTE-ZH.md)。

设备：NVIDIA GeForce RTX 4060 Laptop GPU，8 GiB。D0/D1 使用同 GPU 的独立小池
及真实 socket/registry；native Mooncake GPU 通道使用 TCP，不是 RDMA。没有加载
DSV4.1/Flash 完整权重，也没有运行 SM100 FlashMLA、完整 compressor/indexer 模型
或 HTTP/SSE 网关。分配、请求构建和 scheduler admission 是显式 ABI 夹具。

## CPU / TP

完整插件套件 291 项（包括原有 273 项）通过。D2D 新增覆盖：

- C2 pending half-pair、C4 compressor/indexer、C128 online 与 raw pending-block
  ring，使用 native state registration / index planner 校验实际字节。
- 原生 prebuilt/checkpoint/FutureMap 接续 pending token，避免再次采样或丢失 token；
  原生增量 detokenization 保留已输出文本及游标。
- 原生 FULL/SWA/request-row 预算不足时拒绝分配；native allocation 中途失败不按
  尚未发布的 token map 猜测回收范围。
- 历史复制阻塞时提交 D1；Source native release 只捕获 callback，不提前执行。
- 真实 socket copy reader 在途时，取消和源恢复均等待 reader ref；取消后保留 D0
  row，只释放 D1 一次。commit 后、finished 后和 quarantine 下不能恢复 D0。
- target partial-free 失败后禁止 retry；源端只释放一次。
- 父请求退休 supersede entry 事件后，剩余资源可安全退休，不再查询已清理的 GPU
  event / row；释放 stream/event 引用，恢复 Local overlap 不受残留 target 阻塞。
- 真正双进程 Gloo：一 rank GPU proof 不完整，两端都不能退休；TP quarantine
  保留两端 KV。常规 scheduler poll 和 shutdown 复用同一源端 TP proof 自动回收。

源码预检：49 hooks / 130 native interface contracts；Ruff 的 E9/F63/F7/F82 与
`git diff --check` 通过。

## GPU

[dsv-d2d-4060.json](dsv-d2d-4060.json) 记录八组 D2D 结果及源码 SHA256：

| 压缩 / 布局 | Q/O 通道 | 结果 |
|---|---|---|
| C2 / V4 | TCP、Mooncake GPU | 均通过 |
| C2 / V41（global FP4） | TCP、Mooncake GPU | 均通过 |
| C4 / V4 | TCP、Mooncake GPU | 均通过 |
| C128 / V4 | TCP、Mooncake GPU | 均通过 |

每组先阻塞 global KV copy，再提交 D1；目标缺失的 immutable prefix 被刻意置零。
实际 GPU sparse Remote 输出与独立 union reference 比较，证明输出读取 D0 前缀，
不是误用目标残留数据。随后放行 copy，检查新 tail/padding 的每个字节；真实延迟
CUDA forward event 未完成时源/目标 KV 都不能释放。TP 退休后恢复 native Local，
source free counter 恒为 1。比较容差为 `atol=0.015625, rtol=0.01`；报告同时给出
原始 max error，C128 的 BF16 结果绝对误差不能脱离相对尺度单独解释。

旧 [Flash P→D GPU 回归](dsv-d2d-pd-regression.json) 的四组 C4/C128 TCP/GPU Q/O
同样通过，包括 >512 C128 历史行、native guard 容量、尾页 scatter、在途 GPU reader
取消与重新切 Local。该报告包含对应运行版本的源码 SHA256。

bulk/state 仍是有界 TCP；八组里的 Mooncake 标记只指 Q/O/LSE。当前不能据此推断
整模 TTFT、迁移停顿或 H20 RDMA 吞吐。完整权重长序列、原生流接续和 H20 TP4 是
后续部署验收项。

## 复现

```bash
PYTHONPATH=plugins/remote_attn python -m sglang_remote_attn.check --source-only
PYTHONPATH=plugins/remote_attn python test/manual/remote_attn/dsv_d2d_cuda_probe.py \
  --source-root "$PWD" --output /tmp/dsv-d2d-cuda.json
```

主探针逐子进程隔离 Triton/native Mooncake 扩展和 GPU 注册的生命周期。不会关闭、
覆盖或重新配置目标机上的已有服务。
